Barbearia WJ — Sistema de Gestão

Sistema web desenvolvido para auxiliar na administração da Barbearia WJ, centralizando o controle financeiro, o estoque, o consumo de materiais e a visualização de indicadores do negócio.

O projeto foi desenvolvido com foco em organização, segurança, praticidade e facilidade de utilização.

📌 Sobre o projeto

O **Barbearia WJ** é uma aplicação web de gestão administrativa que permite registrar e acompanhar informações importantes para o funcionamento da barbearia.

O sistema reúne diferentes funcionalidades em uma interface responsiva, facilitando o acompanhamento das operações e a tomada de decisões.

🚀 Funcionalidades

📊 Dashboard
- Visão geral dos indicadores financeiros.
- Acompanhamento de receitas, despesas e saldo.
- Visualização das movimentações registradas.
- Identificação de produtos com estoque baixo.

💰 Gestão financeira
- Cadastro de receitas e despesas.
- Registro de clientes e serviços.
- Identificação de formas de pagamento.
- Consulta do histórico de movimentações.
- Filtros por período e tipo de movimentação.
- Acompanhamento dos resultados financeiros.

📦 Controle de estoque
- Cadastro de produtos e materiais.
- Controle de quantidades disponíveis.
- Definição de estoque mínimo.
- Identificação de produtos em alerta.
- Edição e exclusão de registros.
- Estimativa do valor dos produtos armazenados.

🧴 Consumo de materiais
- Registro da utilização de produtos.
- Acompanhamento do histórico de consumo.
- Integração com o controle de estoque.

👤 Finanças pessoais
- Área específica para organização financeira pessoal.
- Registro e acompanhamento de informações financeiras.
- Persistência de dados no PostgreSQL.

🔐 Autenticação e segurança
- Login com autenticação por sessão.
- Proteção de páginas restritas.
- Armazenamento seguro de senhas com Argon2.
- Cookies de sessão com configurações de segurança.
- Proteções HTTP com Helmet.
- Persistência das sessões no PostgreSQL.

🛠️ Tecnologias utilizadas

| Camada | Tecnologias |
|---|---|
| Frontend | HTML5, CSS3 e JavaScript |
| Backend | Node.js e Express |
| Banco de dados | PostgreSQL |
| Autenticação | Express Session e Argon2 |
| Segurança | Helmet e CORS |
| Sessões | Connect PG Simple |
| Versionamento | Git e GitHub |
